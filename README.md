# Netflix EDA Project

Exploratory Data Analysis on the Netflix Movies & TV Shows dataset, completed as Project 1 for the Pluto Academy AI/ML Internship.

## Dataset
Netflix Movies & TV Shows Dataset
Source: https://www.kaggle.com/datasets/shivamb/netflix-shows

## What this project covers
- Loading and inspecting the dataset (shape, missing values, duplicates)
- Cleaning the data (handling missing values, fixing data types, dropping irrelevant columns)
- Answering 5 exploratory questions using Pandas (content type breakdown, top countries, movie duration stats, top ratings, yearly content growth)
- 6 visualizations: pie chart, line chart, histogram, bar chart, scatter plot, and heatmap
- A 5-point business insights report based on the findings
